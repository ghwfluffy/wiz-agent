# ghwsquad Android observer knowledge

The Proxy Apps capability registry explains the human-installed ghwsquad Android
observer: confirmed trades, near-trade comparisons, dependency/terminal execution
errors and SOL wallet history. One-use website pairing grants revocable observation
and own-device notification preferences only. No delegated assistant API, execution,
trading, administrator or terminal capability is added. Never obtain pairing codes
or device credentials as model context. The orchestration repo owns deployment
hostnames, tunnel-profile wiring and app paths.
