# ghwsquad Android observer knowledge

The Proxy Apps capability registry explains the human-installed ghwsquad Android
observer: confirmed trades, near-trade comparisons, dependency/terminal execution
errors and SOL wallet history. One-use website pairing grants revocable observation
and own-device notification preferences only. No delegated assistant API, execution,
trading, administrator or terminal capability is added. Never obtain pairing codes
or device credentials as model context. The orchestration repo owns deployment
hostnames, tunnel-profile wiring and app paths.

Proxy Apps also supports Codex-only entries with no localhost web server or
site route. Site forwarding is optional per app; desktop configuration still
chooses the directory and CLI command. This adds no delegated execution action.

Human terminal navigation includes Response history, pending Questions, Back to
prompt, touch/mouse scrolling, page and arrow navigation, and a dedicated Enter
that preserves the text-box draft. Page keys move between questions in a
multi-question prompt. The text box supports typed or dictated answers. Controls
use default desktop Codex key mappings and the existing authenticated terminal
socket; they add no transcript storage or assistant access.
